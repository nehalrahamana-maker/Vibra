# Vibra 🎵

An ultra-sleek, modern, and immersive web music player experience built with modern web technologies.

![Vibra Banner](https://images.unsplash.com/photo-1511671782779-c97d3d27a1d4?auto=format&fit=crop&w=1200&q=80)

## ✨ Features

- 🎧 **Interactive Audio Player**: Smooth play, pause, seek bar, volume control, loop, and shuffle modes.
- 🌊 **Real-Time Visualizer**: Dynamic animated audio wave & frequency visualizer.
- 🎚️ **Custom Equalizer Presets**: Bass Boost, Vocal, Electronic, Pop, and Rock profiles.
- 🎨 **Glassmorphism Aesthetic**: Vibrant dark mode with glowing accents, animated mesh gradients, and fluid micro-interactions.
- 📜 **Curated Playlists & Local Track Upload**: Listen to built-in royalty-free demo tracks or drop in your own MP3 / audio files.
- 📱 **Fully Responsive**: Beautiful across desktop, tablet, and mobile screens.

## 🚀 Tech Stack

- **HTML5 & Semantic Structure**
- **Modern Vanilla CSS3** (Custom design tokens, glassmorphism, flexbox/grid, keyframe animations)
- **Vanilla JavaScript (ES6+)** (Web Audio API, dynamic playlist state machine, local storage persistence)

## 💻 Getting Started

To run Vibra locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/nehalrahamana-maker/Vibra.git
   ```
2. Open `index.html` in your favorite web browser, or use a live server extension.
